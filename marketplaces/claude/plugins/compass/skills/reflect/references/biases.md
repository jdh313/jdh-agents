# Self-Deception Patterns and Neutral Probes

A reference for recognizing common ways the user may be deceiving themselves, with neutral probe phrasings that surface the pattern *without naming it as a bias*.

Load this when:

- The user's reasoning sounds rehearsed, defensive, or oddly conclusive given the topic
- The user keeps reaching for the same justification
- The user's affect doesn't match their stated position
- Something feels off but the agent can't articulate what

**Critical rule:** Never label the user as exhibiting a bias. Saying "this sounds like sunk cost fallacy" is an accusation, and the user will defend rather than examine. The probes below surface the *shape* of the pattern by asking a question only that pattern would make hard to answer.

---

## Sunk cost

**Shape:** Decisions weighted by what's already been spent (money, time, identity, public commitment) rather than what's still recoverable.

**Tells:** "I've already put X into this," "I'd be wasting Y if I stopped," frequent reference to history rather than future.

**Neutral probes:**
- "If you were starting fresh today, with no history, would you still pick this?"
- "What would change about your answer if you'd only invested half as much?"
- "What does the past investment make you owe the future?"

## Identity preservation

**Shape:** Defending a position because changing it would mean revising the user's self-image, not because the position is right.

**Tells:** "I'm the kind of person who...", "I've always been a [X]-person," strong reactions to mild challenges.

**Neutral probes:**
- "Is this a preference, or a position you've defended long enough that it feels like one?"
- "If you imagined yourself ten years from now, would the version of you who'd already changed your mind look like a betrayal — or like growth?"
- "What part of this would you have to revise about yourself if you chose differently?"

## Peer-driven preference

**Shape:** A want that originated in observing others want it, dressed as personal preference.

**Tells:** Specific recent exposure ("a friend got one," "I've been seeing more people use..."), enthusiasm that postdates exposure rather than predates it.

**Neutral probes:**
- "When did this first show up on your radar?"
- "If no one ever knew you'd done this, would you still want to?"
- "Whose voice is that — yours, or someone else's?"
- "If [specific person] hadn't mentioned it, would we be having this conversation?"

## Recency bias

**Shape:** Recent events looming larger than their actual weight in the decision.

**Tells:** A specific recent incident keeps anchoring the framing; the urgency feels new.

**Neutral probes:**
- "How long has this been on your mind?"
- "If [recent event] hadn't happened, would this question still feel urgent?"
- "What was your view on this two months ago?"

## "Ought-to" framing

**Shape:** Confusing what one believes one *should* want with what one actually wants.

**Tells:** "I should want this," "It would be smart to," "Everyone says I should," reasoning that sounds borrowed.

**Neutral probes:**
- "Is the feeling 'I want this' or 'I want to be the kind of person who wants this'?"
- "Where did the 'should' come from?"
- "If 'should' weren't a word you could use, how would you describe how you feel?"

## Loss aversion

**Shape:** Overweighting the pain of a potential loss compared to the equivalent gain.

**Tells:** Risks loom much larger than upsides; "what if it doesn't work" dominates "what if it does."

**Neutral probes:**
- "What's the upside you're hoping for, in concrete terms?"
- "If both the worst and best outcomes are equally likely, which one are you mostly thinking about?"
- "If you imagine the upside as vividly as the downside, does the balance shift?"

## Permission-seeking

**Shape:** Already decided, but presenting the question as open in order to get cover.

**Tells:** Resistance to questions that would reopen the choice, framing alternatives as obviously inferior, a sense that any answer the agent gives is being checked against a target.

**Neutral probes:**
- "Are you trying to decide, or trying to feel allowed to decide?"
- "If I told you to go ahead, how would that feel? If I told you not to?"
- "What would it look like if you decided this without consulting anyone?"

## Avoidance dressed as decisiveness

**Shape:** Picking something quickly to escape the discomfort of holding the question open.

**Tells:** "I just need to pick something," urgency that's about ending the deliberation, not about the underlying timeline.

**Neutral probes:**
- "Is the urgency about the decision, or about how it feels to not have decided?"
- "What happens if you sit with this for a week?"
- "What's the cost of taking longer to decide vs. the cost of deciding wrong?"

## Halo effect

**Shape:** One strong feature making the whole option seem better than it is.

**Tells:** A single feature gets repeated; weaknesses get hand-waved; the option is described in superlatives.

**Neutral probes:**
- "If you set [strong feature] aside, how does the rest of it look?"
- "What's the weakest part of this option?"
- "If the strong feature were missing, would you still be considering it?"

## Status quo bias

**Shape:** Defaulting to the current state because it's familiar, not because it's better.

**Tells:** Reasons against change are vivid and specific; reasons for change are vague.

**Neutral probes:**
- "If you were in the new state already, would you switch back?"
- "What would have to be true for the current state to be the right answer on its own merits, not just by default?"

## Future-self optimism

**Shape:** Justifying a purchase or commitment by an idealized future self who will use it more, work harder, change habits.

**Tells:** "I'll really use it once I...", "this will help me start...", reasons that depend on behavior change the user hasn't already demonstrated.

**Neutral probes:**
- "Has past-you done the thing future-you is being counted on to do?"
- "If you assumed future-you behaves exactly like present-you, does this still make sense?"
- "What evidence do you have that the new version of you will show up?"

## Anchoring

**Shape:** The first option, price, or framing the user encountered shaping the rest of the conversation.

**Tells:** All comparisons are made relative to the first one mentioned; the original anchor is rarely questioned.

**Neutral probes:**
- "If you'd encountered [other option] first, where would the conversation have started?"
- "What's the actual range here, ignoring the first number you saw?"
- "Is [original option] the reference because it's the best, or because it was first?"

## Confirmation-seeking

**Shape:** Looking only for evidence that supports a position already held.

**Tells:** Counterexamples get dismissed quickly; the user keeps returning to the same supporting points; questions that should open new ground produce reassurance instead of inquiry.

**Neutral probes:**
- "What evidence would change your mind?"
- "What would the strongest version of the opposing view sound like — in your own voice?"
- "If you had to argue against yourself for two minutes, what would you say?"

---

## Cross-cutting move

When two or more patterns are showing up at once, the cleanest move is often:

> "Pretend a friend you trusted brought you exactly this question, with exactly your reasoning. What would you say back to them?"

This externalizes the user from their own argument and surfaces patterns they'd see in someone else but miss in themselves.
