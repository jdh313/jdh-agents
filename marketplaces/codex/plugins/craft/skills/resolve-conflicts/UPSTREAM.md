# Upstream divergences — resolve-conflicts

_Upstream: `mattpocock/skills` · `skills/engineering/resolving-merge-conflicts` (renamed) · ledger current as of `reviewed_sha: 321658273cb1`_

Intentional divergences from upstream. Reviewed via `skillsmith:upstream-review` (intake 2026-08-29) — do not re-flag these as findings. Read by `upstream-review` only; never referenced from `SKILL.md`.

Upstream is five numbered steps and no prose: see the state, find the primary sources, resolve each hunk, run the project's automated checks, finish the merge/rebase. All five are kept, in order, and upstream's three load-bearing rules ride with them — preserve both intents, do not invent new behaviour, always resolve and never `--abort`. Everything below is the local layer on top.
