## 2026-08-10: markdown lessons — self-contained HTML retired

This forks hard from upstream's self-contained-HTML model — deliberately, not incidentally. Rows 29 and 37 above are marked SUPERSEDED rather than deleted so the earlier reasoning (and why it stopped applying) stays legible.

| Kind | What | Why |
|------|------|-----|
| changed | Lessons: HTML file → `type: lesson` markdown note, participating in the graph (frontmatter, wikilinks, Breadcrumbs, query). `./lessons/*.html` → `./lessons/*.md`. | An HTML lesson had no frontmatter, no wikilinks, no place in the hierarchy, and no participation in any query — teaching didn't accumulate and the agent couldn't tell what the user already knew. Verified empirically (probe against the live vault, 2026-08-10) that a self-grading quiz works in a markdown note with zero JS and zero plugin — only a CSS snippet — which is what made retiring HTML possible without losing the interactive feedback loop that was the reason for HTML in the first place. |
| added | Wiki/lesson split: prose lives once, on a `Reference/` wiki concept page; a lesson transcludes the canonical `## Gist` heading rather than restating content. Lessons may embed only from a small canonical heading set (rename-fragility constraint on heading embeds). | A lesson and a wiki page differ by tense, not scope — wiki is state (re-read), a lesson is process (rarely revisited). Two copies of the same prose guarantees drift; a lesson that *is* the wiki page permanently pollutes reference material with quiz scaffolding. Upstream has no wiki to split against — this divergence only exists because lessons now live in the same graph as everything else. |
| changed | Reference sheets: `./reference/*.html` (print-beautiful cheat sheets, algorithm cards, syntax cards) → ordinary `Reference/` wiki pages, created via `wiki-create` / `wiki-graduate`.
