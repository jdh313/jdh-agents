# linux-ops

Linux sysadmin best practices plugin for Debian/Ubuntu systems. Covers user management, permissions, packages, SSH, networking, systemd, storage, security hardening, and troubleshooting.

## Skills

| Skill | Description |
|-------|-------------|
| `users` | User/group management, service accounts, sudo, PAM |
| `permissions` | File permissions, ACLs, ownership, umask, sticky/setgid |
| `packages` | apt, unattended-upgrades, pinning, release management |
| `ssh` | SSH hardening, key management, config best practices |
| `networking` | Static IPs, DNS, netplan/systemd-networkd, troubleshooting |
| `systemd` | Unit files, timers, journald, service management |
| `storage` | Mount options, fstab, disk health, filesystem ops |
| `security` | fail2ban, UFW, sysctl hardening, audit |
| `troubleshoot` | High load, disk space, network issues, log analysis |

## Agents

| Agent | Description |
|-------|-------------|
| `audit` | Audit a host's security and configuration posture |
