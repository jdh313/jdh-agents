# Shake Tune

Interpret Klippain Shake Tune results for 3D printers. Reads PNG graphs using multimodal vision, diagnoses issues, explains findings in plain language, and recommends mechanical or firmware fixes.

The `/shake-tune` skill orchestrates — detects test types, loads printer-profile context, and synthesizes results — while five specialist agents (one per test type, model tier chosen per how much visual judgment the test requires) own all diagnostic logic. `/shake-tune` is the single entry point; the agents are dispatched internally and aren't meant to trigger organically.

## Features

| Feature | Description |
|---------|-------------|
| Belt comparison | Assess belt balance, diagnose tension differences (CoreXY) |
| Input shaper | Recommend shaper type/frequency, produce Klipper config snippets |
| Vibration profile | Identify safe print speeds, hot spots, slicer recommendations |
| Axes map | Validate accelerometer placement and axis mapping |
| Excitation | Targeted frequency investigation for vibration source diagnosis |
| Printer profiles | Context-aware advice based on your printer's hardware |
| Historical tracking | Save summaries for before/after comparison |

## Quick Start

1. Install: `/plugin install shake-tune@cc-marketplace`
2. Run: `/shake-tune`
3. Provide the path to your Shake Tune results directory
4. Follow the guided analysis flow

Or ask directly: "analyze my belt comparison graph" or "what shaper should I use?"

## Supported Tests

| Shake Tune Macro | File Pattern | Agent |
|-----------------|-------------|-------|
| `COMPARE_BELTS_RESPONSES` | `beltscomparison_*.png` | belt-analyzer |
| `AXES_SHAPER_CALIBRATION` | `inputshaper_*_x.png` / `*_y.png` | shaper-analyzer |
| `CREATE_VIBRATIONS_PROFILE` | `vibrations_profile_*.png` | vibration-analyzer |
| `AXES_MAP_CALIBRATION` | `axesmap_*.png` | axes-map-analyzer |
| `EXCITATE_AXIS_AT_FREQ` | `staticfreq_*.png` | excitate-analyzer |

## Printer Profiles

Optional `.shake-tune-profile.json` file enables context-aware recommendations. The plugin will offer to create one interactively. Supports CoreXY, cartesian, delta, and hybrid CoreXY kinematics.

## Requirements

- Claude Code with multimodal vision (reads PNGs directly)
- Shake Tune results as PNG files (generated by Klippain Shake Tune macros)
- No Python dependencies or raw data parsing needed
